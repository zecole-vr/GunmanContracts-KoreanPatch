# Gunman Contracts 한국어 패치

Gunman Contracts - Stand Alone의 비공식 한국어 패치입니다.

- 패치 버전: **v.1.0.0 — 나눔고딕 교체판**
- 대상: Windows Steam 게임 빌드 **0.3.0.6**
- 정품 게임 설치가 필요합니다. 게임 본편과 저장 데이터는 포함하지 않습니다.
- 기존 독일어 슬롯을 한국어로 대체합니다. 무기명은 원문을 유지합니다.

## 다운로드

이 저장소의 Releases에서 `GunmanContracts-KoreanPatch-v.1.0.0.zip`을 받으세요. 릴리스가 아직 없으면 배포 준비 중입니다.

압축 비밀번호: `zecole`. AES 암호화 ZIP을 지원하는 압축 프로그램이 필요합니다. 저장소의 Code → Download ZIP은 패치 설치 파일이 아닙니다.

## 설치

1. 게임을 완전히 종료합니다.
2. 배포 ZIP을 폴더에 전부 풉니다.
3. `설치.cmd`를 실행하고 관리자 권한 요청을 승인합니다.
4. 기본 경로를 찾지 못하면 게임 설치 폴더를 선택합니다.
5. 완료 후 게임 언어를 `한국어`, 자막을 `모두`로 선택합니다.

별도 Python 설치는 필요하지 않습니다. 압축 안의 파일과 data 폴더는 함께 보관하세요. 파일 해시가 맞지 않으면 설치가 중단됩니다. 강제로 적용하지 마세요.

## 복원

게임을 종료한 뒤 배포 폴더의 `복원.cmd`를 실행합니다. 완료 후 언어를 English로 선택하세요. 게임 데이터 폴더의 `KoreanPatchBackup-v.1.0.0/original` 백업은 삭제하지 마세요. 복원은 이전 시험판이 아니라 패치 전 게임 원본으로 돌아갑니다. 게임 업데이트 후에는 이전 백업을 수동으로 덮어쓰지 마세요.

## 포함 내용과 제한

메뉴·설정·튜토리얼, 의뢰 3개의 브리핑·목표·대사, 적 외침, 뉴스, 일부 고정 문구와 UI 배치를 수정했습니다. 화자 표시는 총잡이·관리자·갱스터 등으로 번역했습니다.

- 나눔고딕 교체 후 실제 VR에서의 줄바꿈·가독성은 최종 확인이 필요합니다.
- 영어 선택 시에도 일부 고정 문구와 화자 이름은 한국어로 남습니다.
- 원래 독일어를 사용하려면 복원해야 합니다.
- 미확인 장면의 미번역이 남을 수 있으며, 100% 번역 완료를 의미하지 않습니다.
- 다른 게임 빌드와 업데이트 이후 버전은 지원이 확인되지 않았습니다.

설치·복원은 테스트용 게임 파일 사본에서 13개 대상 파일의 해시로 검증했습니다. 이 검증이 모든 게임 장면의 정상 동작을 보장하지는 않습니다.

## 문제 제보

Issues에 패치 버전, 게임 빌드, 임무·장소, 재현 순서와 스크린샷을 남겨주세요. 개인정보와 개인 경로는 가려 주세요. 게임 파일·원본 백업·세이브 전체는 첨부하지 마세요.

## 권리 및 폰트

개인이 제작한 비공식 한국어 패치이며, 개발사의 공식 제품이나 공식 지원 대상이 아닙니다. 게임 자산의 권리는 해당 권리자에게 있습니다. 나눔고딕 기반 추가 글자는 SIL OFL 1.1을 따르며, `licenses/OFL.txt`와 `licenses/폰트_라이선스_안내.txt`를 참고하세요. 이 폰트 라이선스는 게임 자산이나 패치 전체에 대한 이용 허락이 아닙니다. 저장소 전체에 적용되는 별도 오픈소스 라이선스는 지정하지 않았습니다.
