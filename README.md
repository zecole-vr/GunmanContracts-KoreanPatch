## 설치

**[ZECOLE_Launcher.exe 받기](https://github.com/zecole-vr/zecole-launcher/releases/latest/download/ZECOLE_Launcher.exe)** · 설치 없이 바로 실행 · 설치·업데이트·원본 복구를 모두 런처에서 합니다.

1. Steam 업데이트를 완료하고 게임을 완전히 종료합니다.
2. 런처를 실행하고 왼쪽 목록에서 **Gunman Contracts**를 고릅니다.
3. **한글패치 설치**를 누르고 관리자 권한 요청을 승인합니다.
4. 완료 후 게임 언어를 `한국어`(독일어 자리), 자막을 `모두`로 선택합니다.

### 알아 둘 점

- 패치 데이터가 커서(약 1GB) 처음 설치할 때 받는 데 시간이 걸립니다.
- 파일 해시가 맞지 않으면 설치가 중단됩니다.
- 이전 패치 사용자는 Steam 업데이트가 완료된 지원 버전 원본에 설치하세요.
- 새 한글패치 버전이 나오면 런처가 **업데이트 있음**으로 알려 주며, 같은 화면에서 설치하면 됩니다.

## 복원

1. 게임을 종료합니다.
2. 런처의 Gunman Contracts 화면에서 **원본 복구**를 누릅니다.
3. 완료 후 게임 언어를 English로 선택하세요.

- 원본 백업(`GunmanContracts_Data/KoreanPatchBackup-v.1.0.2/original`)은 삭제하지 마세요.
- 복원은 지원 버전의 패치 전 게임 원본으로 돌아갑니다.
- 게임 업데이트 후에는 이전 버전 백업을 수동으로 덮어쓰지 마세요.

## 소식 번역 범위와 제한

- 게임에 내장된 업데이트 소식은 번역했습니다.
- 새 **‘소식’ 화면에서 Steam으로부터 실시간으로 받아오는 기사 본문은 원문으로 유지합니다.**
- 영어 선택 시에도 일부 고정 문구와 화자 이름은 한국어로 남습니다.
- 원래 독일어를 사용하려면 복원해야 합니다.
- 검수 완료가 모든 장면의 100% 번역·무결함을 뜻하지는 않습니다.
- 다른 게임 빌드와 이후 업데이트는 지원이 확인되지 않았습니다.
