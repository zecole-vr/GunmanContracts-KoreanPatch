Gunman Contracts - Stand Alone의 비공식 한국어 패치입니다.

- 최신 패치: **v.1.0.2 — 게임 0.3.1.1 대응**
- 대상: **Windows Steam 0.3.1.1 / Steam Build ID 25666351**
- 2026-10-02 실제 게임 사용자 검수 완료.
- 정품 게임 설치가 필요합니다. 게임 본편과 저장 데이터는 포함하지 않습니다.
- 독일어 슬롯을 한국어로 대체합니다. 무기명은 원문을 유지합니다.

## 다운로드

[최신 v.1.0.2 릴리스](https://github.com/zecole-vr/GunmanContracts-KoreanPatch/releases/tag/v.1.0.2)에서 `GunmanContracts-KoreanPatch-v.1.0.2.zip`을 받으세요.

압축 비밀번호: **`zecole`**. AES ZIP을 지원하는 압축 프로그램을 사용하세요. Code → Download ZIP 또는 자동 생성된 Source code ZIP은 패치 설치 파일이 아닙니다.

이전 [v.1.0.1](https://github.com/zecole-vr/GunmanContracts-KoreanPatch/releases/tag/v.1.0.1)은 게임 0.3.1.0 전용, [v.1.0.0](https://github.com/zecole-vr/GunmanContracts-KoreanPatch/releases/tag/v.1.0.0)은 게임 0.3.0.6 전용으로 보관합니다.

## 설치

1. Steam 업데이트를 완료하고 게임을 완전히 종료합니다.
2. 배포 ZIP을 폴더에 전부 풉니다.
3. `설치.cmd`를 실행하고 관리자 권한 요청을 승인합니다.
4. 기본 경로를 찾지 못하면 게임 설치 폴더를 선택합니다.
5. 완료 후 게임 언어를 `한국어`, 자막을 `모두`로 선택합니다.

별도 Python 설치는 필요하지 않습니다. 압축 안의 파일과 data 폴더는 함께 보관하세요. 파일 해시가 맞지 않으면 설치가 중단됩니다. 이전 패치 사용자는 Steam 업데이트가 완료된 지원 버전 원본에 설치하세요.

## 복원

게임 종료 후 같은 배포 폴더의 `복원.cmd`를 실행합니다. 완료 후 언어를 English로 선택하세요. `GunmanContracts_Data/KoreanPatchBackup-v.1.0.2/original` 백업은 삭제하지 마세요. 복원은 지원 버전의 패치 전 게임 원본으로 돌아갑니다. 게임 업데이트 후에는 이전 버전 백업을 수동으로 덮어쓰지 마세요.

게임에 내장된 업데이트 소식은 번역했습니다. 새 **‘소식’ 화면에서 Steam으로부터 실시간으로 받아오는 기사 본문은 원문으로 유지합니다.**

- 영어 선택 시에도 일부 고정 문구와 화자 이름은 한국어로 남습니다.
